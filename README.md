O nome do arquivo e sua presença no GitHub não provam vigência. “Fonte primária” aponta onde consultar; não transforma uma minuta em Constituição promulgada. “Praticou” não significa “domina” nem autoriza ensinar. Títulos históricos não equivalem a cargos atuais.

Usar os estados: VIGENTE; VIGENTE EM TRANSIÇÃO; PARA VISTAS; APROVADO E NÃO PROMULGADO; HISTÓRICO; SUPERADO COM RASTRO; REVOGADO; QUARENTENA; RASCUNHO; SEM ESTADO CONFIRMADO. Sem evidência suficiente, usar o último.

## Ficha mínima para cada entrada

`id; título; escopo; categoria; fonte/URL/caminho; versão; data; autoridade declarada; evidência da autoridade; estado literal; estado validado; classificação de acesso; pertencimento; predecessora; sucessora; hash e método; leitura realizada; conflito; próxima ação; responsável; última verificação`.

Para Google Docs, um hash do texto exportado identifica aquela captura, não a versão nativa inteira. Para GitHub, guardar commit ou blob SHA. Para arquivos locais, usar SHA-256 dos bytes quando a leitura estiver autorizada. Nomes iguais são candidatos a duplicação, não prova de igualdade.
